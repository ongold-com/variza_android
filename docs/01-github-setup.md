# ۱) ساخت APK روی GitHub (بدون نصب هیچ چیزی روی کامپیوتر)

همه‌ی کارها توی سایت GitHub انجام می‌شه. بیلد روی سرورهای خود GitHub اجرا می‌شه.

## قدم ۱: گذاشتن API Key (مهم)
1. ریپو `variza_android` رو توی GitHub باز کن.
2. بالای صفحه روی **Settings** بزن.
3. از منوی سمت چپ: **Secrets and variables** ← **Actions**.
4. دکمه‌ی سبز **New repository secret**.
5. **Name:** `API_KEY` — **Secret:** کلید API بک‌اندت. بعد **Add secret**.
6. (اختیاری) اگه اسم هدر بک‌اندت `X-API-Key` نیست، یه Secret دیگه با اسم `API_KEY_HEADER` بساز و اسم هدر (مثلاً `Authorization`) رو توش بنویس.

> اگه Secret رو نذاری، بیلد انجام می‌شه ولی اپ بدون هدر API Key درخواست می‌فرسته.

## قدم ۲: کلید امضا (یک‌بار، حدود ۳ دقیقه)
برای اینکه آپدیت‌های بعدی اپ روی نسخه‌ی قبلی نصب بشن، یه کلید امضای ثابت لازمه. راهنما: [04-signing-key.md](04-signing-key.md).
(اگه این مرحله رو رد کنی، بیلد باز هم کار می‌کنه ولی برای هر نسخه‌ی جدید باید اپ قبلی رو پاک کنی.)

## قدم ۳: اجرای بیلد
1. بالای صفحه‌ی ریپو روی تب **Actions** بزن.
2. از لیست سمت چپ **Build APK** رو انتخاب کن.
3. سمت راست دکمه‌ی **Run workflow** ← برنچ ← **Run workflow**. (با هر push هم خودکار اجرا می‌شه.)
4. چند دقیقه صبر کن تا تیک سبز بیاد (بار اول ۵ تا ۸ دقیقه).

اگه ✗ قرمز شد، روی اجرا بزن، مرحله‌ی قرمز رو باز کن و متن خطا رو برام بفرست.

## قدم ۴: دانلود APK
1. روی اجرای موفق (تیک سبز) کلیک کن.
2. پایین صفحه بخش **Artifacts**، فایل **variza-sms-apk** رو دانلود کن (zip هست).
3. zip رو باز کن؛ داخلش `variza-sms.apk` هست. به گوشی منتقل کن (تلگرام، کابل، …) یا از مرورگر گوشی دانلود کن.

## (اختیاری) Release با لینک ثابت
تب **Releases** ← **Draft a new release** ← تگ مثل `v1.0.0` بساز و منتشر کن؛ APK خودکار به Release اضافه می‌شه.

بعدش برو سراغ [02-install-on-phone.md](02-install-on-phone.md).

# ۳) درخواست‌های اپ به بک‌اند و روش تست

همه‌ی درخواست‌ها `POST` هستن و هدر `X-API-Key` (اسم هدر از `API_KEY_HEADER` و مقدار از `API_KEY`، همونی که توی `.env`/Secret بیلد گذاشتی) رو دارن.

## ورود
`POST https://variz.aongold.ir/api/v1/app/login`
```
{ "identifier": "09123456789", "password": "...", "label": "phone" }
```
جواب موفق شامل `deviceToken` (و `deviceId` و `user`) است. توکن برای همیشه (تا خروج) روی گوشی ذخیره می‌شه.

## ارسال پیامک
`POST https://variz.aongold.ir/api/v1/app/messages`
```
Authorization: Bearer <deviceToken>
{ "from": "+989121234567", "body": "متن دقیق پیامک", "receivedAt": 1732270000000, "simSlot": 0, "subscriptionId": 1 }
```
- **موفق** فقط وقتیه که جواب 2xx باشه و در `results` همه‌ی موارد `parsed: true` و `matched: true` داشته باشن.
- هر حالت دیگه (خطای شبکه، کد غیر 2xx، `parsed` یا `matched` برابر false) = خطا و اپ **هر ۱۰ ثانیه** دوباره می‌فرسته. پیامی که بک‌اند هیچ‌وقت parse نکنه تا ابد تلاش مجدد می‌شه؛ اگه نخواستی، فرستنده رو از لیست حذف کن.
- بعد از موفقیت، نوتیفیکیشن با مبلغ (`amount`) و بانک (`bankId`) نشون داده می‌شه.

## سناریوهای تست
| تست | نتیجه‌ی درست |
|---|---|
| ورود با رمز غلط | پیام خطا زیر فرم |
| ورود درست، بستن و باز کردن اپ | مستقیم صفحه‌ی اصلی |
| فرستنده‌ی توی لیست پیامک بفرسته | «✓ ارسال شد» و نوتیفیکیشن |
| از شماره‌ای که توی لیست نیست پیامک بیاد | فقط توی «گزارش دریافتی» با دلیل |
| اینترنت قطع باشه | «⟳ تلاش مجدد»؛ با وصل شدن اینترنت ≤ ۱۰ ثانیه می‌ره |
| دکمه‌ی خروج | همه‌چیز پاک و برگشت به صفحه‌ی ورود |
| ری‌استارت گوشی | بدون باز کردن اپ فوروارد ادامه دارد |

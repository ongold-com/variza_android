# ۴) کلید امضا (یک‌بار)

اندروید آپدیت رو فقط وقتی روی نسخه‌ی قبلی نصب می‌کنه که با **همون کلید** امضا شده باشه. کلید رو داخل ریپو نمی‌ذاریم؛ توی Secretهای GitHub نگه می‌داریم.

## ساخت کلید (بدون هیچ نصبی)
1. ریپو ← تب **Actions** ← از لیست سمت چپ **Generate signing key (run once)** ← **Run workflow**.
2. بعد از تیک سبز، روی اجرا کلیک کن و پایین صفحه از **Artifacts** فایل **signing-secrets** رو دانلود کن (zip). داخلش `signing-secrets.txt` هست.
3. فایل رو باز کن؛ چهار خط داره: `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`، `KEYSTORE_BASE64`.
4. ریپو ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret** و برای هر چهار خط یه Secret بساز: اسم = قبل از `=`، مقدار = بعد از `=`.
5. فایل دانلودشده رو پاک کن. (Artifact خودش بعد از ۱ روز پاک می‌شه.)
6. **یه نسخه‌ی کپی از این چهار مقدار جایی امن نگه دار.** اگه گم بشن باید کلید جدید بسازی و اپ قبلی رو از گوشی پاک کنی.

از این به بعد هر بار **Build APK** اجرا بشه با همین کلید امضا می‌کنه و آپدیت‌ها روی هم نصب می‌شن.

## اگه کلید عوض شد
اپ قبلی رو از گوشی Uninstall کن و دوباره نصب کن (لیست شماره‌ها و آدرس پاک می‌شن).
